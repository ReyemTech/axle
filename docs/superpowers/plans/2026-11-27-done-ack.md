# Done Column Ack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The board's Done column shows only finished work the owner has not seen; the owner acks it off the board, old work auto-acks at read time, and every done task stays reachable on a History page.

**Architecture:** Two nullable columns on `tasks` (`done_at`, `acked_at`) set by the store. "Unseen" and "auto-acked, unseen" are SQL predicates over `done_at` against `now − N`, so nothing is ever written by a timer and changing N takes effect at once. `TaskFilter` grows the fields the Done column, History and `task_list` need, so all three query in SQL with `LIMIT`.

**Tech Stack:** Rust, axum 0.8, askama 0.16, htmx, sqlx 0.9 (SQLite + Postgres), tokio.

**Spec:** `docs/superpowers/specs/2026-11-27-done-ack-design.md`

## Global Constraints

- Migration `0004_done_ack.sql` in **both** `migrations/sqlite/` and `migrations/postgres/`; never edit 0001–0003.
- N = `AXL_DONE_AUTO_ACK_DAYS`, default **7**, integer ≥ 1; invalid values fail startup with `ConfigError::BadNumber("AXL_DONE_AUTO_ACK_DAYS", raw)`.
- *Unseen* = `status = 'done' AND acked_at IS NULL AND done_at >= now − N`. *Auto-acked, unseen* = `status = 'done' AND acked_at IS NULL AND done_at < now − N`. Exactly N days old is unseen.
- Nothing is deleted; no background job; ack never changes a task's status, version or `updated_at`; agents cannot ack (no MCP tool).
- Store timestamps come from the caller's `Clock`; queries never call `now()` / `CURRENT_TIMESTAMP` (store/mod.rs header rule).
- History pages hold **50** tasks, newest `done_at` first, cursor-paged.
- `task_list` gains boolean `include_acked` (default `false`); other statuses are unaffected.
- UI copy follows DESIGN.md: every button has a verb label ("Ack", "Ack all", "Ack these"); no glyph-only controls; no hard-coded "7 days" in copy.
- Every ack POST is CSRF-checked by the existing `require_session` middleware, answers 303, and publishes `Event::TaskChanged`.
- CHANGELOG is release-plz's job; do not edit it.

## Review Focus

1. **`back` redirect target on ack forms** — a crafted `back=//evil.example` or `back=https://…` must land on `/ui/board`, never off-site. Test in Task 5.
2. **Title search with `%`, `_` or `\`** — they match literally, and case is ignored (`"FIX"` finds "fix the flaky test"). Test in Task 2.
3. **Ack of ids that are not done, unknown, or garbage** — unknown/non-done ids are skipped without error; an unparsable id is a 422, and nothing is acked when any id in the batch is unparsable. Tests in Tasks 3 and 5.
4. **A task that leaves `done`** — `done_at` and `acked_at` are both cleared, and a second trip into `done` gets a fresh `done_at` (so it shows as unseen again). Test in Task 1.
5. **History cursor across equal `done_at`** — tasks finished in the same instant still page without gaps or duplicates (order is `(done_at DESC, id DESC)`). Test in Task 2.

```rust
pub struct TaskFilter {
    // existing: project, status, owner, parent, after, limit
    /// Only tasks with no parent.
    pub top_level: bool,
    /// How `done` rows are filtered; rows of any other status always pass.
    pub done: DoneFilter,
    /// Case-insensitive substring of the title; `%`, `_` and `\` match literally.
    pub title: Option<String>,
    /// Row order; also what `after` is a cursor into.
    pub order: TaskOrder,
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub enum DoneFilter {
    #[default]
    Any,
    /// `acked_at IS NULL AND done_at >= since` (since = now − N).
    Unseen { since: OffsetDateTime },
    /// `acked_at IS NULL AND done_at < since`.
    AutoAckedUnseen { since: OffsetDateTime },
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub enum TaskOrder {
    /// `(created_at, id)` ascending; `after` = rows after the cursor (today's behaviour).
    #[default]
    Created,
    /// `(done_at, id)` descending; `after` = rows older than the cursor.
    DoneNewest,
}

/// `q` as a LIKE pattern with `\` as the escape: `%q%` with `% _ \` escaped.
pub fn like_pattern(q: &str) -> String;

// Store trait:
/// How many tasks `list_tasks(filter)` would return ignoring `after`, `limit` and `order`.
async fn count_tasks(&self, filter: &TaskFilter) -> StoreResult<u64>;
```

```rust
/// In one transaction: for each listed id whose task is `done`, sets `acked_at = now` on it
/// and on every `done` descendant, wherever `acked_at` is still null. Ids that are unknown
/// or not done are skipped (their descendants too). Returns the ids newly acked.
async fn ack_done_tasks(&self, ids: &[TaskId], now: OffsetDateTime) -> StoreResult<Vec<TaskId>>;

// TaskService
/// The human's ack. Publishes `Event::TaskChanged { kind: TaskEventKind::Acked, .. }` once
/// for each listed id that is in the newly-acked set. Writes no task_events row.

impl AckState { pub fn as_str(self) -> &'static str; } // "unseen" | "acked" | "auto-acked"
/// `None` unless the task is done.
pub fn ack_state(task: &Task, now: OffsetDateTime, auto_ack: Duration) -> Option<AckState>;
```

```rust
pub const DONE_COLUMN_LIMIT: u32 = 50;

}
pub struct ColumnView { /* existing */ pub done: Option<DoneHead> }   // Some only for Done

// actions.rs
/// POST /ui/tasks/{id}/ack  (form: csrf, back)
pub async fn ack_task(State, Path(id), Form(AckForm)) -> UiResult<Response>;
/// POST /ui/done/ack  (form: csrf, back, repeated `id`) — Ack all and History's Ack these
pub async fn ack_done(State, RawForm) -> UiResult<Response>;
/// `back` if it is `/ui/board…` or `/ui/history…` (and not `//`), else `/ui/board`.
fn ack_back(back: &str) -> &str;
```
